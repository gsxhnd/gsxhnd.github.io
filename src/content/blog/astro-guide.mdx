# Astro 开发指南

Astro 是一个**以内容为中心**的 Web 框架，专注于构建快速、以内容为中心的网站。它的核心设计理念是**岛屿架构**，允许你在静态页面中注入交互式组件。

## 为什么选择 Astro

### 性能优先

Astro 的核心理念是**默认零 JavaScript**。这意味着页面加载时不会发送任何不必要的 JavaScript，从而获得极快的加载速度。

```astro
---
// 这是一个 Astro 组件
const title = 'Hello Astro';
---

<h1>{title}</h1>
<p>这段代码在构建时渲染为纯 HTML，零 JavaScript。</p>
```

### 岛屿架构

当需要交互性时，Astro 允许你使用**岛屿**（Islands）将交互式 UI 组件注入到静态页面中。

```astro
---
import InteractiveCounter from '../components/Counter.jsx';
---

<!-- 静态内容 -->
<h1>我的页面</h1>

<!-- 交互式岛屿 -->
<InteractiveCounter client:load />
```

## Content Collections

Astro 的内容集合（Content Collections）提供了一种类型安全的方式来管理 Markdown 和 MDX 内容。

### 定义 Schema

```typescript
import { defineCollection, z } from 'astro:content';

const blog = defineCollection({
  type: 'content',
  schema: z.object({
    title: z.string(),
    description: z.string(),
    pubDate: z.coerce.date(),
    tags: z.array(z.string()).default([]),
  }),
});
```

### 查询内容

```typescript
import { getCollection } from 'astro:content';

const posts = await getCollection('blog');
```

## 最佳实践

1. **优先使用服务端渲染** - 尽可能在构建时渲染内容
2. **谨慎使用客户端指令** - 只在需要交互性的组件上使用 `client:*` 指令
3. **利用图片优化** - 使用 Astro 的 `<Image />` 组件自动优化图片
4. **类型安全** - 利用 Content Collections 的 Schema 验证确保数据一致性

## 总结

Astro 是现代静态站点生成的优秀选择，特别适合以内容为中心的网站，如博客、文档和营销页面。它的性能优势和开发者体验使其成为构建快速网站的首选工具。
