# 欢迎来到我的博客

这是我的第一篇博客文章，很高兴能在这里与你分享我的想法和见解。

## 关于这个博客

这个博客使用 [Astro](https://astro.build) 构建，Astro 是一个现代化的静态站点生成器，专注于性能和开发者体验。结合 Tailwind CSS 和 Markdown，我可以专注于内容创作，而不必担心繁琐的配置。

## 技术栈

- **Astro** - 快速、以内容为中心的 Web 框架
- **Tailwind CSS** - 实用优先的 CSS 框架
- **Markdown / MDX** - 轻量级标记语言

## 未来计划

我会在这里分享关于前端开发、技术探索以及个人成长的内容。希望这些文章能对你有所帮助。
